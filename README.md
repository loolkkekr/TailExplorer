# TailExplorer
This project was created for personal use to create mods for Unity Games. TailExplorer is a copy of UnityExplorer, which, unlike UnityExplorer, supports MelonLoader 0.7+ Mono. Don't expect good code, as everything was written using AI. If you are ANTI-AI, I don’t care, I repeat, this project was created exclusively for me and I just published it, hoping that my mod might help someone.

Requirements:

MelonLoader 0.7+

Unity Type: Mono
